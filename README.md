# Nudgelight releases

Downloads for **Nudgelight**, a macOS app that shows your coding agents' status — on this Mac and on other machines over SSH — at the notch or the top of the screen.

This repository only hosts release files and the update feed. It contains no source code.

- Download the latest version from [Releases](https://github.com/nudgelight/releases/releases/latest): `Nudgelight-<version>.zip`, unzip, move **Nudgelight.app** to Applications.
- Nudgelight 0.1.6 and later check for updates here and ask before installing.
- Preview builds are not notarized yet: on first launch, right-click the app → Open → Open.

# Nudgelight 下載

**Nudgelight** 是 macOS app，把 coding agent 的狀態（這台 Mac 與經 SSH 連到的其他機器）顯示在螢幕瀏海或上緣。

這個 repo 只放發行檔與更新來源，不含原始碼。

- 從 [Releases](https://github.com/nudgelight/releases/releases/latest) 下載最新的 `Nudgelight-<版本>.zip`，解壓縮後把 **Nudgelight.app** 拖進「應用程式」。
- 0.1.6 起，app 會到這裡檢查新版，安裝前會先問你。
- 試用版還沒經過 Apple 公證：第一次打開請在 app 上按右鍵 → 打開 → 打開。
